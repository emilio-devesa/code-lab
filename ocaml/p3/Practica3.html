  1. En ocaml pueden hacerse definiciones recursivas si añadimos la palabra reservada "rec" justo después de "let". Así, por ejemplo, podría definirse la función "factorial":

    let rec fact n =
        if n <= 1 then 1 else n * fact (n-1);;

Defina en ocaml una función fib: int -> int, que sirva para representar la sucesión de Fiboacci. (Recuerde que, para cada n natural,  fib n = n si n es 0 o 1 y en otro caso fib n = fib (n-1) + fib (n-2)).

Defina en ocaml una funcion sumto: int -> int, que, para cada n natural, devuelva la suma de todos los naturales de 0 a n.

  1. El principal problema de estas definiciones de fact y fib es que, al tratarse de funciones que crecen muy rápidamente, en seguida los valores se salen del rango del tipo de dato int.

Redefina las funciones fact y fib para que tengan tipo int -> float y podamos calcular así valores más grandes.


  1. El problema del tipo float es que nos trabaja con una aritmética aproximada. Así, las funciones anteriores nos dan sólo una idea de la magnitud de las imágenes, pero no su valor exacto. En el módulo Num de la librería Num está definido un tipo de dato "num", que sirve (entre otras cosas) para representar en ocaml números enteros arbitrariamente grandes y operar con ellos con precisión absoluta.

Al comienzo del capítulo dedicado en el manual de ocaml a la librería Num, se explica cómo utilizar esta librería, tanto desde el compilador interactivo como desde el compilador batch.

Recuerde que para utilizar los nombres definidos dentro de un módulo (que no sea de la "core library") es preciso "calificarlos" poniendo delante el nombre del módulo con un punto (por ejemplo, Num.add_num). Esto puede evitarse con la directiva de compilación open (en este caso sería open Num;;) que indica al compilador cómo resolver los nombre no "calificados". Esto permite además utilizar los operadores que se usan en modo infijo (entre dos operandos) y que en el manual aparecen entre paréntesis. En el caso del módulo Num puede resultar muy cómodo utilizar operadores como (+/),  (-/) , ( */)  o  (//).

  2. Cuando se solicita la ejecución de un programa desde la línea de comandos del sistema operativo (shell), pueden a la vez pasársele parámetros, escribiéndolos después del nombre del programa. Desde un programa ocaml puede accederse a los valores de estos parámetros consultando el vector de strings predefinido Sys.argv. El nombre del programa será el valor del elemento 0 del vector (Sys.argv.(0)) el primer parámetro será el valor del elemento 1 (Sys.argv.(1)), etc. El número de palabras utilizadas en la línea de comandos al invocar el programa coincidirá con el valor de la expresión  Array.length Sys.argv.

    Utilizando los valores de este vector y la función print_endline (ya usada en la práctica 1), puede construirse un programa que calcule el factorial de un número tomando el argumento de la línea de comandos y mostrando el resultado por la pantalla .

    % fact 10
    3628800
    %
